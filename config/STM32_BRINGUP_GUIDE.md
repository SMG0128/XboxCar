# STM32 首次上车指南

## 烧录前

1. 暂时不连接任何电机和电机电源，只连接 STM32、ST-Link。
2. 检查 `App/Inc/app_config.h` 中四个 `MOTOR_*_INVERTED` 默认值。
3. 确认左右 TB6612 的 STBY 已通过硬件上拉到 3V3。
4. 确认左右 TB6612 的 VM 已通过飞线连接到合适的电机电源。
5. STM32、ESP32、TB6612 逻辑地和电机电源地必须共地。
6. PB0/PB1 超声波通道保持断开；默认只启用 FRONT、REAR、RIGHT 三路测距。
7. OLED 电源由 PB6(GND)/PB7(3V3) 提供（GPIO 推挽输出，上电即置位）；I2C 仍在 PB8/PB9。

## 无电机检查

1. 编译并烧录固件，保持电机断开。
2. 上电后用示波器或逻辑分析仪确认 PA6、PA1、PB3、PB15 初始为低。
3. 确认 PA2/PA3、PA4/PA5、PA12/PA15、PA8/PA9 初始均为低。
4. 在 PB11 送入合法 115200 8N1 控制帧，观察对应 PWM。
5. 停止发帧，确认不超过 300 ms 四路 PWM 立即变低。
6. 发送急停帧，确认立即归零；随后连续三帧普通控制帧才恢复。

## 逐电机接入

1. 只接一个电机，先发送绝对值 100..200 的低速命令。
2. 确认“正值向前”；若相反，只修改对应 `MOTOR_*_INVERTED`。
3. 依次测试左前、左后、右前、右后，避免一次接入四路后难以定位。
4. 四轮方向正确后，测试直行、后退、左右转和原地旋转。
5. 最后测试 ESP32 断电、拔掉 UART、按下急停时能否立即停车。

不要在 VM/STBY 未修正、PB1 接入 5 V ECHO 或车辆架起措施不足时上地面测试。

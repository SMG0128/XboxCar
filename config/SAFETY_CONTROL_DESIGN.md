# 安全控制设计

## 状态优先级

```text
内部故障 > 锁定急停 > 通信超时 > 超声波限制 > 普通控制 > 速度斜坡
```

上电处于 `STARTUP_SAFE`，输出级关闭。首个完整合法、序号可接受的帧后进入
`ONLINE`。任何非在线状态都调用立即停车路径，将目标、当前速度、方向和 PWM
同时归零，不等待减速。

## 急停与通信

- CMD 7 和 CMD 15 锁定急停；
- 普通帧不能单帧解除，连续 3 帧合法非急停帧后才解除；
- 错误帧中断恢复计数；重复帧不计数，也不刷新通信时间；
- 解除周期仍保持零请求，下一帧从零开始加速；
- 距上个接受帧达到 300 ms 即通信超时并立即停车；
- 超时只按每次断线计数一次，恢复后重新建立序号基线；
- UART 接收无法重新启动、PWM 时钟不匹配和状态损坏属于锁定内部故障。

## 障碍限制

超声波启用时，前方只限制正向分量，后方只限制反向分量，因此车辆始终可以向
远离障碍的方向退出。停止距离内对应方向为零；停止与慢速距离之间线性降速；
释放距离提供滞回。侧面传感器只限制继续靠近该侧的转向，不直接全车急停。

传感器故障策略可配置。默认 `FAIL_OPEN` 是因为超声波硬件默认关闭；在传感器、
电平转换和安装角度完成实车验证前，不能把它描述为已验证的自动避障。

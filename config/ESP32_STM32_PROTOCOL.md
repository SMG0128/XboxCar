# ESP32–STM32 控制协议

## 选择依据

仓库现有 ESP32 固件已经使用并实机验证 30 字节 ASCII 协议，因此本 STM32 工程
兼容该协议，没有切换到附件中的备用 12 字节二进制协议。ESP32 已负责读取
`throttle/steering`、死区、差速和第一层斜坡，STM32 接收最终 `LEFT/RIGHT`。

## UART 与接线

```text
115200 baud, 8 data bits, 1 stop bit, no parity
ESP32 GPIO43 TX -> STM32 PB7 / USART1_RX (full remap)
STM32 PB6 / USART1_TX -> ESP32 GPIO44 RX（当前可不接）
ESP32 GND        -> STM32 GND
```

控制 UART 不发送调试日志，避免污染协议。

## 帧

```text
$XC,<CMD>,<LEFT>,<RIGHT>,<SEQ>,<CRC>\r\n
```

固定 30 字节。例如：

```text
$XC,0001,+0800,+0800,0025,1D\r\n
```

| 字段 | 格式 |
| --- | --- |
| CMD | 4 位二进制动作码 |
| LEFT/RIGHT | `+0000..+1000` 或 `-0000..-1000` |
| SEQ | `0000..9999`，允许 9999 后回到 0000 |
| CRC | 两位大写十六进制 XOR |

CRC 初始为 0，对帧索引 1..24（字符 `X` 到 SEQ 末位）逐字节 XOR；不包含 `$`、
CRC 字段和 CRLF。

动作码：`0000` 停止、`0001` 前进、`0010` 后退、`0011` 左转、`0100` 右转、
`0101` 左旋、`0110` 右旋、`0111` 急停、`1000` 无输入、`1001` 断线、
`1111` 错误。

解析器可以从任意字节重新寻找 `$`，忽略 Bluepad32 日志；错误 CRC、长度或字段不
刷新超时。数值越界或 UART 环形缓冲/硬件严重错误会触发锁定急停。连续 300 ms
没有合法帧会立即停车。

# ESP32–STM32 控制协议

## UART 与固定帧

```text
ESP32 GPIO43 TX -> STM32 PB7 / USART1_RX（full remap）
STM32 PB6 / USART1_TX -> ESP32 GPIO44 RX（当前可不接）
115200 baud, 8 data bits, no parity, 1 stop bit
```

控制 UART 不发送调试日志。帧固定为 30 字节：

```text
$XC,<CMD>,<LEFT>,<RIGHT>,<SEQ>,<CRC>\r\n
$XC,0001,+0800,+0800,0025,1D\r\n
```

| 字段 | 规则 |
| --- | --- |
| `CMD` | 4 位二进制；允许 0..9 和 15 |
| `LEFT/RIGHT` | 符号加 4 位十进制，范围 `-1000..+1000` |
| `SEQ` | 4 位十进制，9999 后回到 0000 |
| `CRC` | 两位大写十六进制 XOR |

CRC 初值为 0，覆盖索引 1..24（`X` 到 SEQ 末位），不包含 `$`、CRC 字段和
CRLF。动作码：0 停止、1 前进、2 后退、3 左转、4 右转、5 左旋、6 右旋、
7 急停、8 无输入、9 手柄断开、15 错误。

CMD 0、7、8、9、15 无条件把左右速度改为零；CMD 7 和 15 进入锁定急停。

## 流式接收

USART1 中断只把单字节写入 256 字节单生产者/单消费者环形缓冲并重启接收。
主循环负责寻找 `$`、组帧和全部解析，因此支持噪声、拆包、粘包、截断后重同步
和超长错误后的恢复。环形缓冲溢出丢弃最新字节并计数，损坏的候选帧不会刷新
看门狗。

以下项目全部通过才是可接受控制帧：帧头、固定长度、逗号位置、CRLF、CMD 二进制
格式、数值格式与范围、SEQ、CRC，以及序号分类。

## 序号与在线状态

- 首帧建立序号基线；
- 相同序号是重复帧，不更新控制、不刷新看门狗、不计入急停恢复；
- 正向步进 1..100 可接受，跳帧会计入序号异常；
- 正常在线时，超出窗口的序号先作为重启候选，下一帧连续后才重建基线；
- 通信超时后放宽一次基线，恢复的首个非重复合法帧可立即建立新序列；
- 9999 到 0000 是正常回绕；旧帧不能持续覆盖新帧。

只有完整合法且序号可接受的帧才更新 `last_accepted_ms`。CRC、格式、范围、旧序号
和重复帧都不能延长 300 ms 在线时间。
